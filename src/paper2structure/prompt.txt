the broader project would have the following agents: 1. summary agent, 2. technique (1...N) agents, 3. structural hypothesis agent, 4. builder agent, 5. revision/consistency agent. each agent has the following tasks. "summary agent" takes a paper as input, and then provides the following output: a. read and identify the techniques used in the paper. b. read and identify the materials used in the paper, c. extract images from the paper and map them to the techniques and materials. "technique K agent" accesses the images for that technique, analyze the image and gather information helpful to create a structure. "structural hypothesis agent" consumes all the outputs from "technique (1..N) agents" and proposes the dimensions of the unit cell, structure construction details, molecules present in the cell, surface construction, etc. "builder agent" uses ase to construct the structure. "revision agent" checks for consistency between techniques and the structure. right now, we are working on the "summary agent" and "technique agents". verify what portion of the tasks are being implemented in the existing code and what should be changed? do not make code changes.
